L7 looper

A 7-track stereo looper for the Dirtywave M8. Record loops from line in or USB. Layer, crop and mix them, arrange combinations as scenes and export to an Ableton Live project.

Install Help

Install

Looking up the latest release…

This browser can't talk to the M8. Installing from the page needs WebHID, which Chrome and Edge have on a computer (not on phones or tablets). Open this page in one of those, or install by hand with the steps under "Install without this page" below.

  1. Connect the M8 to this computer with a USB data cable, then switch it on.
  2. Quit anything else that uses the M8 over USB: M8C, the headless display, Teensy Loader, TyCommander, a serial monitor.
  3. Click Install, and choose the M8 when the browser asks. The page restarts it into its loader and installs.

Go back to the M8's own firmware

Downloads the latest firmware from Dirtywave's downloads page and installs the file for your M8's model. It comes straight from Dirtywave to your browser; this site doesn't host it. Installing it means you agree to Dirtywave's licence (EULA.txt in their download).

Install a .hex file from your computer

For a test build, or an older version of L7 or of the M8's firmware. The page checks the file is for your M8's model before it writes anything.

If something goes wrong

    
It's safe to try again

    
The M8's loader sits on its own chip, and installing never overwrites it. If an install stops partway, the M8 waits in its loader: click Upload to try again. After reloading the page, click Install, close the browser's pop-up, then click Upload. Installing doesn't touch the SD card, so your projects and recordings stay put, whichever firmware you install.

    
The M8 isn't in the browser's pop-up

    
Check the M8 is switched on, and try another cable (some only charge). If the M8 is already in its loader (after a stopped install, for instance), it doesn't show there: close the pop-up and click Upload.

    
An Upload button appears

    
The M8 is waiting in its loader: click Upload and choose it when the browser asks. Cancel goes back to the start.

    
Upload's pop-up is empty

    
The M8 didn't restart into its loader. Click Cancel, check nothing else is using the M8 (see the next point), then click Install again.

    
"Couldn't open the M8's USB port"

    
Another app has it. Quit M8C, Teensy Loader, TyCommander and any serial monitor (such as the Arduino IDE's), then try again.

    
"Nothing was written"

    
The .hex file you chose is built for the other M8 model. Your M8 is unchanged: choose the file for your model.

    
The screen stays dark after "Done"

    
Switch the M8 off and on.

    
Linux

    
Install PJRC's udev rules for Teensy (the M8 is built around a Teensy), then unplug and replug the M8.

Menu

    
The menu holds your 12 projects as cards A–L, with export, storage mode, the settings and help listed below them. A new install starts here. Move with the arrows, and go past the screen's edges to get back to the looper. Press EDIT on a card to open that project for editing, or on an empty card to start a new one. OPT works as EDIT in the menu.


    
Getting started

    
    
      
  • ▲ ▼ ◀ ▶: select a track or a cell. Moving past the screen's edges goes to the menu.
    • 
      
  • EDIT is the action button. The icon at the bottom right of the screen shows what it will do on the selected cell.
        
      
          
    • On a menu card: on an empty card, start a new project and go to the looper. On a used card, load that project. (OPT works as EDIT in the menu.)
      • 
          
    • On an empty track: record from the next bar line (if the clock is stopped, this starts it). Press EDIT again to stop at the end of that bar. In a new project, a metronome clicks until the first loop is done.
      • 
          
    • On a full track: mute / unmute.
      • 
        
    
      
    • 
      
  • SHIFT + EDIT: cancel a recording, cut the clip, or paste onto an empty track.
    • 
      
  • OPT + arrows: edit the selected cell. OPT twice resets it.
        
      
          
    • Waveform: ◀ ▶ moves the loop range, ▲ ▼ makes it longer / shorter (reset: the whole loop).
      • 
          
    • Filter: ◀ ▶ moves the band, ▲ ▼ widens / narrows it (reset: open).
      • 
          
    • Volume: ▲ ▼ sets the track volume, ◀ ▶ the stereo balance (reset: unity, centred).
      • 
        
    
      
    • 
    


    
Clock

    
    
      
  • START: play / stop.
    • 
      
  • SHIFT + START: resume from where the clock stopped (restart if it's playing).
    • 
      
  • OPT + arrows on the tempo cell: ±0.1 BPM (◀ ▶) / ±1 BPM (▲ ▼). The loops stretch to the new tempo and keep their pitch.
    • 
      
  • EDIT on the tempo cell: tap tempo.
    • 
      
  • OPT + EDIT on any bottom row cell: metronome on / off.
    • 
    


    
Scenes

    
A scene is a snapshot of all 7 tracks: which clip each one plays, its range, mute, filter, volume and balance. Anything you change is saved into the current scene as you go, so there's no save step. The bottom row shows where you are as SCN n/N, and a project holds up to 200 scenes.

    
Two scenes at the ends of the list behave differently: they aren't stored until you change them. Below scene 1 is 0* (shown as 0/N), an empty scene. A new project starts there, so your first recording turns it into scene 1, and changing anything on 0* later inserts a new scene 1 and moves the others up. Above the last scene is N+1* (shown as */N), a copy of it. Changing anything there makes it a new last scene, so to build the next part of a song, step up to N+1* and change or record something.

    
    
      
  • SHIFT + OPT twice: duplicate the scene.
    • 
      
  • SHIFT + ▲ ▼: next / previous scene, on the beat after you let go of SHIFT.
    • 
      
  • OPT + EDIT on an empty track: resample what you hear into a new scene.
    • 
      
  • EDIT on the scene cell: next scene. SHIFT + EDIT there duplicates it.
    • 
      
  • SHIFT + ▲ ▼, three quick taps: jump to the copy of the last scene (N+1*) or to the empty one (0*).
    • 
      
  • SHIFT, OPT, EDIT in that order: cut the scene.
    • 
      
  • OPT, SHIFT, EDIT in that order: paste the scene after this one.
    • 
    


    
More

    
    
      
  • OPT + arrows on the clock cell: master volume (▲ ▼) and stereo balance (◀ ▶).
    • 
      
  • EDIT held + ▲ ▼ after a mute: swipe the same mute across tracks. Going back the other way undoes it.
    • 
      
  • SHIFT + ◀ ▶: previous / next recording on the card.
    • 
      
  • OPT + EDIT + ▲ ▼ on a track: move a track that has a clip.
    • 
      
  • OPT + any cell + EDIT: nudge by ¼ beat (held: in ms steps).
    • 
      
  • SHIFT + ◀ ▶ on the bottom row while playing: nudge the tempo faster / slower, like Live's nudge buttons.
    • 
      
  • SHIFT + EDIT on the tempo cell: audio follow (it follows the tempo heard in the input).
    • 
      
  • SHIFT + EDIT in the menu on a project slot: cut a project (hold) / paste it into a slot.
    • 
      
  • Menu → Export: an Ableton Live set in /L7/EXPORTS.
    • 
      
  • Menu → Storage mode: the SD card shows up as a USB drive. Any key exits.
