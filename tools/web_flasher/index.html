Install L7 on your M8

L7 is a 7-track stereo looper firmware for the Dirtywave M8. Install it from this page over USB, with nothing else to set up.

Install

Looking up the latest release…

This browser can't talk to the M8. Installing from the page needs WebHID, which Chrome and Edge have on a computer (not on phones or tablets). Open this page in one of those, or install by hand with the steps under "Install without this page" below.

  1. Connect the M8 to this computer with a USB data cable, then switch it on.
  2. Quit anything else that uses the M8 over USB: M8C, the headless display, Teensy Loader, TyCommander, a serial monitor.
  3. Click Install. The first time, the browser asks you to choose the M8 (the page restarts it into its loader), then the loader; pick the one entry each time. After that, Install goes straight through.

Install a .hex file from your computer

For a test build, or an older version of L7 or of the M8's firmware. The page checks the file is for your M8's model before it writes anything.

Go back to the M8's own firmware

Downloads the latest firmware from Dirtywave's downloads page and installs the file for your M8's model. It comes straight from Dirtywave to your browser; this site doesn't host it. Installing it means you agree to Dirtywave's licence (EULA.txt in their download).

If something goes wrong

    
It's safe to try again

    
The M8's loader sits on its own chip, and installing never overwrites it. If an install stops halfway, the M8 stays in its loader: click Upload to try again, or Install after reloading the page. Installing doesn't touch the SD card, so your projects and recordings stay put, whichever firmware you install.

    
The M8 isn't in the list

    
Try another cable (some only charge). If the M8 is already in its loader (after a stopped install, for instance), close the list and click Upload.

    
The second list doesn't open

    
The browser only opens it by itself for a few seconds after the click. If it doesn't, the page shows an Upload button: click it and choose the loader.

    
"Couldn't open the M8's USB port"

    
Another app has it. Quit M8C, Teensy Loader, TyCommander, the Arduino IDE's serial monitor, then try again.

    
Linux

    
Install PJRC's udev rules for Teensy (the M8 is built around a Teensy), then unplug and replug the M8.
