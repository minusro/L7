K6 — SIX-TRACK CLIP MACHINE

A fresh app for the M8 hardware (320x240, d-pad + SHIFT/PLAY/B/A). Clip grid + piano roll paradigm, UX designed for muscle memory: a spatial screen map, one edit grammar everywhere, explicit copy/paste verbs, sound on every edit. Reuses the proven engine layer (board, synth pool, FX, GM region).

THE SCREEN MAP

Six screens on a 3x2 spatial map, moved with SHIFT+arrows (wrapping). Vertical position means zoom: below GRID sits the selected clip's notes, below MIX the selected track's sound. The map position shows as a 3x2 dot cluster in every screen's top bar, so you always know where you are.

SONG / GRID / MIX across the top; PROJ / NOTE / INST beneath them.

THE GRAMMAR (every screen, no exceptions)

Arrowsmove the cursor
SHIFT + arrowsmove across the screen map
A tapact: launch, toggle, place
A held + arrowsedit the primary value (U/D coarse, L/R fine)
B held + arrowsedit the secondary value
B tapzoom into the detail screen for the cursor's object
B double tapreset to default
SHIFT + Acut on full / paste on empty (L7's card grammar: clips, notes, project cards)
SHIFT + Bcopy to the clipboard without removing
PLAY / SHIFT+PLAYstop | start from 1.1.1 / reset | resume
PLAY held + arrowstempo, anywhere (U/D ±1, L/R ±0.1 BPM)
B + PLAYoverdub on/off (MIDI records into the playing clip)
A + B + arrowsglobal: select track (L/R) / step the playing clip (U/D)

A is the EDIT key, B is OPTION.

GRID (home)

6x6 clips + the scene column on the right; the top bar carries the map dots, clock, tempo and play state. The selected track underlines; playing cells show a playhead; the scene cells launch whole rows (clock-synced).

NOTE (below GRID)

The piano roll: scale-only rows (drum tracks show one row per sound), velocity as fill brightness in a full-colour outline, marquee selection with B-drag, wrapped notes draw and select across the loop point.

SONG (left of GRID)

The arranger: an ordered list of scene rows with repeat counts. A adds a row at the cursor; A-held+arrows changes scene/repeats; B-tap jumps the transport there. PLAY in SONG plays the arrangement; in GRID it plays the grid.

MIX (right of GRID)

Six strips + master: volume, pan, mute/solo, send level, live meters. A toggles mute, B-tap solos, A-held+U/D volume, +L/R pan.

INST (below MIX)

Carried from the proven design: engine selector (40%) + preset box, SYN / MOD / FX tab pages of two knob rows, B-double-tap resets a cell.

PROJ (below SONG)

Project cards (load/save/cut/paste), storage mode, key/scale, metronome, and app switching. The one "menu" screen, still grid-shaped.

DECIDED

  • Spatial 3x2 screen map with SHIFT+arrows; map dots always visible.
  • Clipboard: SHIFT+A cut on full / paste on empty (L7's grammar), SHIFT+B copy.
  • B-tap = universal "zoom into detail" (clip→roll, song row→grid); on MIX it solos.
  • Clips ride the global clock, so launches are instant and keep phase.
  • Every edit sounds: auditioning on all note/value edits while held.
  • Engine layer shared with the N9-era app: pool synths, FX chains, GM region.
