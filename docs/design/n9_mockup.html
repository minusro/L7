N9 Screen Mockups

N9 is L7's sister app on the same M8 hardware: nine MIDI clip tracks, each with its own selectable synthesizer engine. Six screens, stepped through with SHIFT + UP/DOWN, top to bottom: master effects & sends, mixer, track modulation, track instrument, clip grid, clip editor. Notes are edited by hand in the clip editor or recorded from USB/serial MIDI (channel 1 plays and records into the selected track). These screens reuse L7's visual language: the 2×2 block grid, the five greys plus accent, the 3×5 pixel font, and the status row along the bottom. The small dot column at the status row's left shows where you are in the screen stack (accent dot = this screen).

Reused from L7

  • Hardware and chrome — same M8 (Teensy 4.0, 320×240, arrows/SHIFT/PLAY/A/B), same block grid, palette, font, status row (scene · clock · tempo · action button), selection frames, row grounds, badges.
  • Cell grammar — arrows select, B + arrows adjust, B twice resets, A is the context action, SHIFT + A cut/paste.
  • Timing — the master clock, bar-line queueing (clips, scenes, engine switches land on the bar), tap tempo, external MIDI clock follow.
  • Projects — the menu, 12 project slots, scenes; sessions on the SD card under /N9/.

Open questions

  • Four vs six — the brief said four main screens but listed six; are FX and the editor secondary (e.g. only via B + A), or is it simply six in the stack?
  • Scene stepping — SHIFT + UP/DOWN meant scenes in L7 and means screens here. Scenes from the grid only, or keep a shortcut (SHIFT + LEFT/RIGHT?)?
  • Editor style — piano roll (mocked) or an M8-style tracker column? The piano roll suits the d-pad but holds less per screen.
  • Engines — which engines, how many voices per track fit the Teensy beside 9 tracks of mixing and two send effects?
  • Modulation model — free slots (mocked, 3 per track) vs fixed LFO + envelope pages per engine.
  • Clip length — per clip (1–8 bars?) with the grid showing length, or scene-wide like L7?
  • MIDI — channel 1 to the selected track for now; later one channel per track (1–9)?
