N9 Screen Mockups

N9 is L7's sister app on the same M8 hardware: nine MIDI clip tracks, each with its own selectable synthesizer engine. Eight screens, stepped through with SHIFT + UP/DOWN, top to bottom: master FX slots, send effects, mixer, track modulation, track FX, track instrument, clip grid, clip editor. Notes are edited by hand in the clip editor or recorded from USB/serial MIDI (channel 1 plays and records into the selected track). These screens reuse L7's visual language: the 2×2 block grid, the five greys plus accent, the 3×5 pixel font, and the status row along the bottom. The small dot column at the status row's left shows where you are in the screen stack (accent dot = this screen). A prototype of these screens runs on the device (the N9/ sketch in the L7 project folder): screen stack, a cursor on every screen, and first sound — 32 voices on MIDI channel 1, the engine stepped with B + LEFT/RIGHT on INST.

Reused from L7

  • Hardware and chrome — same M8 (Teensy 4.0, 320×240, arrows/SHIFT/PLAY/A/B), same block grid, palette, font, status row (scene · clock · tempo · action button), selection frames, row grounds, badges.
  • Cell grammar — arrows select, B + arrows adjust, B twice resets, A is the context action, SHIFT + A cut/paste.
  • Timing — the master clock, bar-line queueing (clips, scenes, engine switches land on the bar), tap tempo, external MIDI clock follow.
  • Projects — the menu, 12 project slots, scenes; sessions on the SD card under /N9/.

Decided (2026-10-13)

  • Six screens in the stack, SHIFT + UP/DOWN; scenes are no longer launched by SHIFT + arrows (the grid launches them).
  • Piano roll for the clip editor.
  • Modulation — four selectable sources per track, each with two destination slots.
  • Voices — 32, a shared pool across the nine tracks.
  • Engines (27, user-trimmed) — PROPHET, 303, JUNO, then every Mutable Instruments plaits model as its own engine (virtual analog, 6-op FM, wavetable, chords, speech, drums ...). The M1 and Microwave emulations are parked until their real sample/wavetable data is in. The INST cells are live per engine (B + arrows edit: LEFT/RIGHT 1, UP/DOWN 10).
  • FX slots — two selectable FX slots on each track (a screen between modulation and instrument) and two more selectable master FX slots on a topmost screen, above the send effects.
  • Clips — at most 16 bars. A loop brace selects a whole-bar range, which may wrap around the loop boundary. Recordings are a fixed number of bars, starting and stopping on the first beat; the length is set by stopping the clip recording.

Open questions

  • Emulation depth — per-engine CPU cost of the five emulations against the 32-voice pool; measured per block on the prototype's serial log.
  • MIDI — channel 1 to the selected track for now; later one channel per track (1–9)?
