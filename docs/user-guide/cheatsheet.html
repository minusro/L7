L7

7-track looper for the M8 · cheatsheet A = EDIT   B = OPT
  • Tracks 1–7, top to bottom: waveform (bright part plays), filter, volume (level, balance, meter), then the track's button (filled: playing, outlined: muted).
  • Status row: scene SCN 3/7, clock (bar.beat.step), tempo, and the action button, which shows what A will do.
  • The small icon at the bottom left: the menu (projects, export, storage mode).

Move

▲▼ ◀▶Select a row / a cell
Off an edgeTop / bottom: notes ↔ main; sides: the menu (once let go)
◀+▶ heldSwitch screens from anywhere (press both together)

Tracks

A empty trackRecord from the next bar line (clock stopped: starts it, bar 1). Again: stop at the bar's end; within a beat after a bar line, there
A other trackWhile one records: stop it, the next starts where it ends
A full trackMute / unmute (held +▲▼: swipe, solo)
SHIFT+ACut clip / paste onto an empty track / cancel a recording
SHIFT+◀▶Previous / next recording on the card
B+A empty trackResample: record what you hear (needs a clip playing)

Loops are whole bars, up to 32. A metronome clicks in a new project until the first loop is done.
